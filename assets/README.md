# Assets

## Typewriter Sound

For the typewriter click sound effect, you have two options:

### Option 1: Download a free sound
Download a free typewriter key click sound from:
- https://freesound.org/search/?q=typewriter+key
- https://www.zapsplat.com/music/typewriter-sounds/

Save as `typewriter-click.mp3` in this directory.

### Option 2: Use the generated sound
Run the included Node script to generate a simple click sound:

```bash
node generate-sound.js
```

### Option 3: Skip sound
The calculator will work without the sound file - it will simply be silent.
